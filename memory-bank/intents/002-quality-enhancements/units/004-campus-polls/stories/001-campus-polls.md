# Story: Interactive Campus Poll Creation & Voting

As a society administrator or student,
I want to attach a poll to my post with 2 to 4 options,
So that I can gather student feedback on workshop topics and event schedules.

## Acceptance Criteria
- [ ] User can click "Add Poll" in compose form and provide 2 to 4 options.
- [ ] Logged-in users can select one option and click "Vote".
- [ ] Once voted, user sees percentage breakdown and vote count for each option instead of vote buttons.
- [ ] Duplicate votes by the same user are rejected by database unique constraint.
