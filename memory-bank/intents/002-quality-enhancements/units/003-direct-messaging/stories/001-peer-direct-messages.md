# Story: 1-on-1 Direct Messaging Between Peers

As a FAST student,
I want to send a private message to another student directly from their profile,
So that I can coordinate project work, study groups, or discuss course details privately.

## Acceptance Criteria
- [ ] Clicking "Message" on a user profile opens a direct chat thread with that user.
- [ ] Direct message history displays sent and received bubbles with timestamp.
- [ ] Users cannot message themselves.
- [ ] Unread messages display an indicator in the navigation bar.
